# Запуск и обслуживание

## 1. Первый запуск на сервере

```bash
sudo bash deploy/install.sh /path/to/lab-chat
nano /opt/lab-chat/.env
```

В `.env`:

```
DEEPSEEK_API_KEY=sk-...
DEEPSEEK_BASE_URL=https://api.deepseek.com
MODEL_MAIN=<id из проверки ниже>
MODEL_REASONER=
APP_SECRET=<любая случайная строка>
COOKIE_SECURE=1
DB_PATH=data/app.db
```

Проверка ключа и списка моделей:

```bash
/opt/lab-chat/.venv/bin/python /opt/lab-chat/tools/check_deepseek.py
```

Скрипт печатает доступные модели, делает тестовый запрос и показывает расход
токенов. Если `MODEL_MAIN` не совпадает ни с одной — скопировать id из вывода.

## 2. Пользователи

```bash
sudo -u labchat /opt/lab-chat/.venv/bin/python /opt/lab-chat/tools/create_user.py aks1 "Аксён"
```

Повторный запуск с тем же логином меняет пароль. Пароль вводится скрыто.
Регистрации в интерфейсе нет.

## 3. Проверка

```bash
curl -s http://127.0.0.1:8000/health
systemctl status lab-chat
journalctl -u lab-chat -f
```

Открыть сайт, войти, вставить задание, подтвердить карточку, дойти до шага 2,
спросить «вернись к шагу 1».

## 4. Остановка

```bash
systemctl disable --now lab-chat
```

Сервис можно просто выключить, когда он больше не нужен: внешних зависимостей
кроме API DeepSeek нет.

## 5. Данные

- `data/app.db` — пользователи, сессии, прогресс, сообщения.
- `content/modules/*.json` — шаги. Правка шаблона не ломает сохранённые планы:
  у пользователя остаётся скомпилированный план до пересборки.
- Бэкап (WAL нельзя копировать через `cp`):

```bash
sqlite3 /opt/lab-chat/data/app.db ".backup '/opt/lab-chat/data/app.db.$(date +%F)'"
```

- Восстановление: остановить сервис, положить файл на место `app.db`,
  удалить `app.db-wal` и `app.db-shm`, запустить сервис.

## 6. Типичные проблемы

| Симптом | Причина |
|---|---|
| «Модель недоступна» | пустой ключ или неверный `MODEL_MAIN` |
| Ответ на всё — «На шаге N…» | работает mock-режим, ключ не подхватился |
| Сайт не открывается снаружи | нет проброса порта или туннеля |
| Шаг не двигается по «Дальше» | шаг не подтверждён после вопроса (`can_advance=false`) |
| `вернись к шагу 5` не работает | шаг с таким номером вне текущего плана |
