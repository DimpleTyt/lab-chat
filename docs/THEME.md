# Тема интерфейса

Повторяем вид opencode в тёмной теме: чёрный фон, белый текст, моноширинный
шрифт, тонкие границы, минимум декора.

## Токены

```css
--bg:        #0a0a0a;
--bg-panel:  #111111;
--bg-input:  #161616;
--bg-hover:  #1a1a1a;
--border:    #232323;
--border-strong: #333333;
--text:      #ededed;
--text-dim:  #8a8a8a;
--text-faint:#5c5c5c;
--accent:    #fab283;   /* primary, opencode peach */
--blue:      #5c9cf5;
--green:     #7fd88f;
--red:       #e06c75;
--yellow:    #e5c07b;
--radius:    6px;
--mono: ui-monospace, "JetBrains Mono", "Cascadia Code", "SF Mono", Consolas, monospace;
```

## Правила

- Шрифт только моноширинный, размер 14px (команды 13px), межстрочный 1.6.
- Фон страницы `--bg`, панели `--bg-panel`, поле ввода `--bg-input`.
- Границы 1px `--border`. Никаких теней, градиентов, скруглений больше 8px.
- Акцент `--accent` только для: активной кнопки, ссылки, полосы прогресса,
  имени пользователя. Не красить им текст целиком.
- Заголовки — обычный текст с `font-weight: 600`, без крупных размеров.
- Служебные подписи (`ШАГ 12/58`, `МОДУЛЬ 2`) — 11px, uppercase, `letter-spacing: .08em`,
  цвет `--text-faint`.
- Кнопки: фон `--bg-input`, граница `--border`, при наведении `--bg-hover`,
  primary-кнопка — фон `--accent`, текст `#0a0a0a`.
- Код: блок с фоном `#0d0d0d`, граница `--border`, `white-space: pre`,
  горизонтальный скролл, кнопка «Копировать» в правом верхнем углу, появляется
  при наведении.
- Никаких аватарок и пузырей чата. Сообщение пользователя помечено слева
  вертикальной линией `--border-strong` и подписью `ВЫ`; ответ ассистента — без рамки.
- Лента: max-width 760px, по центру, отступы 24px.
- Поле ввода: одна строка с автовысотой, снизу панель с кнопками
  `Дальше` (primary, справа) и подписью `Enter — отправить`.

## Каркас

```
┌──────────────────────────────────────────────────────┐
│ lab-chat        Шаг 12/58 · Модуль 2      user  выйти │
├──────────────────────────────────────────────────────┤
│                                                      │
│  ВЫ                                                  │
│  │ у меня ошибка mdadm: no devices                    │
│                                                      │
│  **Шаг 12/58 · Модуль 2: RAID**                      │
│  ...                                                 │
│                                                      │
├──────────────────────────────────────────────────────┤
│  [ сообщение...                        ]  [ Дальше ] │
└──────────────────────────────────────────────────────┘
```

Левая колонка со списком модулей не нужна. Прогресс — тонкая полоса 2px
под шапкой, шириной `num/total`.

## Экран входа

Центрированная карточка 360px, логотип текстом `lab-chat` моноширинным,
поля логин/пароль, кнопка `Войти` на всю ширину. Ошибка — строка `--red`
под полем, без иконок.

## Карточка задания

Рамка `--border`, две группы строк:

```
ИЗ ЗАДАНИЯ
  RAID 10, 4 диска, /raid10

ИЗ МЕТОДИЧКИ
  домен au-team.irpo, HQ-CLI 192.168.0.65
```

Внизу две кнопки: `Всё верно` (primary) и `Исправить` (обычная).
