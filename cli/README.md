# lab-chat CLI

Терминальный клиент к тому же серверу, что и веб-версия. Работает на стоковом
python3 в Astra Linux, сторонних пакетов не требует.

## Запуск на Астре

```bash
scp labchat.py user@astra:~/
python3 labchat.py
```

Если python3 нет (не должно быть, но вдруг):

```bash
apt-get install -y python3
```

При первом запуске спросит логин и пароль, сохранит сессию в
`~/.labchat/session.json` (права 600). Дальше входить не нужно, пока сессия
активна: час без действий — и попросит пароль снова.

Вставлять текст задания необязательно: можно сразу заполнить таблицу параметров.
В онлайн-версии таблица приходит с сервера и показывает, откуда взято значение:
`задание`, `модель`, `методичка` или `правка`.

```
Параметры задания
   1) Домен                    au-team.irpo
   2) Рабочая группа           au-team
   3) Пароль администратора    P@ssw0rd
   4) Уровень RAID             0
   5) Дисков в массиве         2
   6) Точка монтирования       /raid0
   ...
Номер строки:
```

Enter — принять значения, номер строки — изменить поле, `сброс` — вернуть
значения из методички. При смене уровня RAID количество дисков и точка
монтирования пересчитываются сами, если их не правили вручную. Если вставить
текст задания, таблица заполнится из него, и останется только проверить.

## Команды

```
Enter        следующий шаг
текст        вопрос или описание ошибки
/step N      перейти к шагу N (или к id вида 2.3)
/restart     начать заново
/variant     изменить задание
/repeat      повторить текущий шаг
/copy        показать команду текущего шага отдельно
/logout      выйти
/quit        закрыть программу
```

## Полезные ключи

```bash
python3 labchat.py --server https://exam.nothing-box.com
python3 labchat.py --insecure      # если старый CA-набор не доверяет Let's Encrypt
python3 labchat.py --no-color      # для логов и записи
python3 labchat.py --user roma --password '********'
```

`--user/--password` лучше не использовать на общей машине: пароль останется
в истории shell. Для скриптов есть переменные `LABCHAT_USER`,
`LABCHAT_PASSWORD`, `LABCHAT_SERVER`.

## Если нет интернета

Есть отдельная офлайн-сборка: всё внутри одного файла, сеть не нужна вообще.

```bash
curl -o labchat-offline.py https://exam.nothing-box.com/download/labchat-offline.py
python3 labchat-offline.py
```

Отличия от сетевой версии:

- шаги, команды, разбор задания и карточка работают так же;
- нет входа по логину — файл самодостаточный;
- ответов модели нет: на вопрос или ошибку печатается подсказка из методички
  (частые причины, признак успеха, какую команду повторить).

Офлайн-файл пересобирается из шаблонов командой:

```bash
python tools/build_offline.py
```

Сборщик сам сверяет команды с онлайн-компилятором для RAID 0/1/5/10.
